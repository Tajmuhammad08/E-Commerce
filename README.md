# E-Commerce Product Website

This is a frontend e-commerce website built using HTML, CSS, and JavaScript.
The project focuses on creating a clean UI with well-structured folders and reusable components.

## Features
- Responsive website layout
- Product listing section
- Single product detail page
- Organized CSS architecture
- Reusable UI components

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Folder Structure
css/
- components
- layout
- pages

img/
- products
- categories
- slider
- blogs

js/
- single-product

## How to Run the Project
1. Clone or download the repository
2. Open index.html in your browser
